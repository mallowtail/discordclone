# Polish Implementation Plan (short form — owner asleep, pre-approved scope)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development.

**Goal:** Welcome front page for logged-out visitors; built-in error log (capture → DB → /admin Errors tab) with friendly error screens; fix messages missed while the live connection starts.

**Spec:** `docs/superpowers/specs/2026-11-21-polish-design.md` — binding (Goals, Calls 1–3).

## Global Constraints
- Same dark theme/tokens as the app; works at phone width (320px) with no horizontal scroll.
- Error reports: message ≤ 500 chars, stack ≤ 4000, scrub tokens/emails/query strings; rate-limited; table capped (~5,000 rows); readable/clearable only by the site admin; anonymous visitors may report (rate-limited).
- Logged-in users never see the landing page flash.
- Production has 3 real users — never touch their data; temp test data cleaned up afterwards; CAPTCHA is ON (browser tests log in via admin generate_link → session).
- Read node_modules/next/dist/docs before writing error.tsx/global-error.tsx/route code (AGENTS.md).

## Review Focus
1. log_client_error can't be abused to flood the DB or read others' errors.
2. No private data (message text, tokens, emails) ends up in error rows.
3. The missed-message catch-up doesn't duplicate messages or break paging/anchors.
4. Front page redirects logged-in users correctly (including OAuth/welcome flows).
5. Error boundaries don't hide errors from the log.

### Task 1: Build everything (DB migration + app)
Migration (client_errors table, log_client_error RPC, admin read/clear) with dry run; capture (window error/unhandledrejection + error.tsx/global-error.tsx boundaries); /admin Errors tab; front page; missed-message catch-up in useMessages. Tests for pure helpers. Verify tsc/lint/vitest/build.

### Task 2: E2E, review, ship
Local e2e (front page logged-out + phone width; logged-in redirect; induced error appears on /admin; rate limit; missed-message scenario by sending while the receiver's channel is joining), final review + one fix wave, merge, deploy, prod check, cleanup.
